For authors

Add a chapter

Upload a chapter, or the whole book, as a PDF or Word file. The site converts it and opens a pull request, so nothing is published until the owner merges it.

How it works

  1. You choose the file and say which chapter it is, or that it's the whole book.
  2. This page puts the file in textbook/sources/ on a new branch of the site's GitHub repository and opens a pull request.
  3. GitHub converts the file into the chapter's page, runs the site's checks, and comments on the pull request with anything to fix, such as figures without alt text.
  4. The owner reviews and merges it. The chapter appears on the site a minute later, and the contents page, the study hub and the author pages update with it.

Any PDF works: exported from Word, Google Docs, LaTeX or Pages, one or two columns. Scanned pages (pictures of text) need text recognition first. A whole-book file is split into chapters wherever the book names each chapter, such as "Chapter 3: Sleep, caffeine and jet lag".

What you need

A GitHub account with write access to the site's repository, and an access token from it. Create a fine-grained token for the EnglishWebsite repository with Contents and Pull requests set to "Read and write". This page sends the token only to GitHub and never stores it.

Without this page

You can also upload the file on GitHub, choosing "Create a new branch" and a pull request. Name it after the chapter's id, like neuronal-activity.pdf, or book.pdf for the whole book. Markdown chapters with images go this way too, with their images next to them.
