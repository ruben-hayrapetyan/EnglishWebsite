One look, many hands

Every page on this site is built from the same small set of parts: one color palette, one type scale, one spacing scale and a short list of components. That's what keeps pages built at different times by different people looking like a single site.

The rules live in README.md and AGENTS.md. The values live in one file, assets/css/tokens.css.

Before you add anything

Check the style guide for a component that already does the job. If none fits, add a new one to assets/css/components/ instead of styling inside a page.
