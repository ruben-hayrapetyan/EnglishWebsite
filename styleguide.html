Type

Highlight (signature)

A highlighter stroke behind the key words of a page title. It also marks the current page in the menu and sweeps under links on hover. Use one per screen at most.

Find the one phrase that matters.

Reader settings

Readers change text size, font, spacing and theme on the settings page. Those choices only change tokens, so every component here follows them. The reader bar, reading ruler and notes appear only when a reader uses them, and scripts add them, so never write them by hand. See ACCESSIBILITY.md.

sepiadata-theme="sepia"Warm, low glare
contrast-lightdata-theme="contrast-light"Black on white, blue accent
contrast-darkdata-theme="contrast-dark"White on black, cyan accent
